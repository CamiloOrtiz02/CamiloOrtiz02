* 🔐 **API REST Multi-tenant con Pasarela de Pagos**
  - **Stack:** `Node.js` · `Express` · `TypeScript` · `PostgreSQL` · `Mercado Pago`
  - Arquitectura multi-tenant con aislamiento completo de datos por cliente.

  - **Stack:** `Angular 9` · `PHP` · `MySQL` · `JWT` · `C#` · `Bootstrap`

  - Aplicación de escritorio complementaria en `C#` para integración directa con impresoras térmicas de facturación.
